# RSSWire Playground

A WordPress Playground made for testing **RSSWire**, my WordPress plugin available on the official WordPress.org Plugin Directory.

## Playground Details

- **Platform:** [WordPress Playground](https://playground.wordpress.net/)
- **Site Name:** RSSWire Playground
- **WordPress:** Latest available
- **PHP:** 8.3
- **Plugin:** [RSSWire](https://wordpress.org/plugins/rsswire/)
- **Plugin Source:** WordPress.org Plugin Directory
- **Plugin Activation:** Automatic
- **Login:** Enabled
- **Landing Page:** `/wp-admin/tools.php?page=rsswire`

## Open the Playground

[**Launch RSSWire Playground directly**](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fthoffical%2Ftry-rsswire%2Frefs%2Fheads%2Fmain%2Fblueprint.json)

## About

This is a browser-based WordPress environment where I can test RSSWire without needing to set up a separate WordPress installation.

The Playground Blueprint installs RSSWire directly from WordPress.org and activates it automatically.

## Notes

- Uses the latest available WordPress version and PHP 8.3.
- RSSWire is installed from the official plugin directory.
- Playground data may not persist indefinitely, so don't treat it as permanent hosting.
- RSSWire's features depend on the version installed.
